Ticket: https://app.clickup.com/t/17tnw2b1f21

## Scope and method

Verified with official cargo-cyclonedx 0.5.9, installed into a temporary task directory, Rust 1.98.0 on macOS. Inspected its CLI/source: feature flags feed Cargo metadata; default dependency inclusion is all dependencies. No application crate was compiled, native model downloaded, installer dispatched or deployment performed. Existing lockfiles/manifests are unchanged.

The operator's `stt` feature enables optional `selahcue-stt`, configured with `whisper`, `capture`, `download`. Required identities are `selahcue-stt`, `whisper-rs`, `whisper-rs-sys`, `cpal`, `ureq`. The checker requires Cargo package URLs with matching version, library components and a reachable BOM ref from operator metadata; unrelated display names/documents or disconnected components do not satisfy it. The iterative graph walk terminates on cycles. JSON leaf dependencies may omit `dependsOn` per actual generated output.

Generation uses `--features stt --target all`: a conservative platform union so Linux CI also inventories Windows dependencies shipped by the installer. This is a metadata inventory, not binary attestation or evidence of compiling every platform. Default features remain enabled; unrelated optional operator features are not enabled. The existing desktop workspace SBOM step stays unchanged.

The first graph-check attempt rejected valid leaf nodes lacking `dependsOn`; actual generated output identified this schema error. The checker now treats omitted leaf children as empty and has an explicit regression. Earlier omission results from that attempt are not counted as valid negatives; all five were rerun after a real fixed-document pass.

Generator warnings about project `Proprietary` license expressions being represented as named licenses existed in baseline and fixed output; no policy change or warning suppression was made. Temporary tool installation reported its own locked xml-rs yanked warning; no repository lock was changed.
