## Objective

Deliver the reusable **image render foundation** that both image slides and the theme image element (`86ajq6j49`) will consume: a **bounded, deterministic, panic-contained in-process image decode** (PNG this batch) feeding a new additive **`scene::Layer::Image`** that composites on the deterministic **CPU raster** path, plus a **missing-media / decode-fail placeholder** that never blanks an output (FR-070) and a runtime **decoder-fault** path that contains to the placeholder with other outputs unaffected (NFR-024). Decoded pixels live in a **size-capped in-process cache**, never in the serde `Frame`. This adopts a bounded in-process decode NOW, **refining ADR-0016's sequencing** (its out-of-process sandbox stays the deferred end-state) via a new **ADR-0018**.

## Baseline

Verified from code (read-only trace `wf_f9163b0e-40b`, 5 lenses):
- `scene::Layer` (scene.rs:87-111) is an **internally-tagged** (`#[serde(tag="layer")]`) enum with `Fill{rect,color}` + `Text{rect,text,px,color,align,font}`; it derives **`Eq`** (so a new variant's fields must be `Eq` — rules out `f32`). `Layer` is `Clone` not `Copy` (Text holds a `String`). `Frame{width,height,background,layers:Vec<Layer>,blackout}` also derives `Eq`; layers paint in Vec order. Doc (:84-86): "Richer layer kinds extend this enum without changing the seam."
- `raster::render` (raster.rs:356-376) is a **pure function of the scene**, byte-identical cross-OS (NFR-014); `blend` (:238-253) is integer src-over `(src*sa+dst*ia+127)/255`, output alpha forced 255; `fill_rect` (:342-353) clips to the buffer then blends per pixel. `MAX_DIMENSION=8192` + `is_renderable()` reject hostile sizes. `TextCtx` (thread_local) rebuilds every `RESET_EVERY=4096` renders — the bounded-cache template. `#![forbid(unsafe_code)]` (lib.rs:17); workspace `unwrap_used="warn"`.
- The **GPU** compositor (selahcue-gpu) **re-implements Fill on the GPU and SILENTLY SKIPS `Layer::Text`** (compositor.rs:157-165) as a documented "later batch"; it is **not wired into the desktop shell** (the shell CPU-composites via `raster::render`). `test_parity` asserts **SSIM ≥ 0.99** (not byte-equality) over **six hand-built Fill-only frames**; `analysis::ssim`. Byte-equality is asserted only CPU-side (golden) and GPU-vs-GPU (device-loss).
- `fault::Fault::DecoderFault` already exists (fault.rs:12-21); `Engine::SetScene` holds the last good frame on a bad scene (engine.rs:106-142); `test_fault.rs` proves InjectFault → OutputHeld, other instances unaffected.
- **No image/decoder dependency exists** anywhere. The **`png` crate (0.17.16) + its whole tree** (fdeflate/flate2/miniz_oxide/crc32fast/bitflags/adler2/simd-adler32) are in the offline cargo cache and mostly already in `Cargo.lock` → `png = "0.17"` resolves offline. The full `image` crate is NOT cached.
- **No wire/persist/rbac change is needed:** wire VERSION stays 2, `target_version` stays 12, RBAC unchanged — an image is an additive `Element::Image` inside the **opaque `theme_json`** and a `Layer::Image` in the scene; the `Element` enum (theme.rs:128-153) already reserves the `Image` seam. (Note: the theme `Element::Image` + compose wiring is the follow-up `86ajq6j49`, NOT this batch.)
- ADR-0016 (Accepted) chooses out-of-process sandboxed decode as the end-state, and names process-restart+placeholder as the documented fallback. FR-066 (PNG/JPEG/WebP/GIF/BMP display), FR-070 (missing-media placeholder, never black), FR-173 (memory-safe decoders + header/type/size validation + allowlist before full decode + isolation where feasible), NFR-014 (cross-OS parity), NFR-024 (output-failure isolation), NFR-027 (SBOM/dependency audit).

**Key architecture finding:** unlike `Element::Shape` (which composited to the existing `Layer::Fill`, needing no engine change), an image must **carry pixels**, so it needs a new `Layer::Image` + a new decode step. But because the GPU already skips non-Fill layers and CPU is the real render path, the whole batch lands on the **CPU deterministic path** with **no wire/migration/GPU-pipeline change** — the GPU skips `Layer::Image` exactly as it skips `Text`.

## Scope

### In scope

- **Decode dependency:** add `png` (pinned `0.17`, minimal features) to `selahcue-engine`. Pure-Rust, memory-safe, deterministic, offline-available. SBOM/RustSec audit must stay green (NFR-027).
- **Model (`scene.rs`):** additive `Layer::Image { rect: Rect, source: MediaRef, #[serde(default, skip_serializing_if) ] opacity: u8 }`. `MediaRef` = a **bounded validated** reference (a newtype over a length-capped string, validating Deserialize that rejects empty/over-long, routed through a constructor — the `FontName` pattern) so the wire/IPC can't smuggle an unbounded key; `Eq`-able. Existing `Fill`/`Text` fixtures stay **byte-stable** (internally-tagged + skip-if-default). `opacity: u8` (Eq preserved).
- **Decode core (`selahcue-engine`, new module):** `decode_png(bytes: &[u8], limits: &DecodeLimits) -> Result<DecodedImage, DecodeError>` — a **pure, panic-contained (Result, no unwrap/expect/unsafe)** function: media-type/header validation + a **format allowlist** + a **pre-allocation dimension AND decoded-byte budget cap** (decompression-bomb defense — reject before allocating), decoding to fixed **RGBA8** (no ICC/gamma/premultiply → deterministic). Non-PNG / corrupt / oversize / over-budget → `Err`, never panic.
- **Raster (`raster.rs`):** a `Layer::Image` match arm that resolves `source` via a **bounded decode cache** (a thread_local keyed by `MediaRef`, capped by max entries **and** a total decoded-byte budget, with eviction — the `TextCtx`/`RESET_EVERY` template), then **blits** the decoded RGBA into the FrameBuffer using **integer nearest-neighbor scaling** to the dest rect + the whole-layer **opacity** multiplied into source alpha + the existing integer `blend` (src-over), reusing `fill_rect`'s clip math (frame-bounded, no panic on out-of-bounds rects). On decode-fail/missing/unsupported/over-budget → the **placeholder**.
- **Placeholder (`raster.rs`):** a deterministic engine-drawn **distinct non-black** "media missing/failed" visual (FR-070) drawn with existing fill primitives — never blank, never crash.
- **Fault path:** confirm/wire that a runtime `Fault::DecoderFault` contains to the placeholder with the last-good frame held and other outputs unaffected (NFR-024), via the existing engine OutputHeld/fault contract.
- **ADR-0018:** adopt bounded in-process PNG decode now; refine ADR-0016's **sequencing** (keep its sandbox end-state); preserve **fault** isolation now, defer **security** isolation (sandbox) as the seam the `Layer::Image`/decode boundary later plugs into.
- **Tests:** PNG cross-OS **golden-byte** determinism on the CPU raster; adversarial (crafted/corrupt/truncated/oversized/decompression-bomb → placeholder, no panic); **bounded** decode cache over many decodes/frames (no-leak); missing/unsupported → placeholder; decode-fault-contains-to-placeholder (test_fault style); additive serde byte-stability (Fill/Text unchanged).

### Non-goals (seams — note)

- The theme **`Element::Image`** (per-mille rect + fit + opacity + z + bounded media ref) + `compose` Element→`Layer::Image` + **on-canvas authoring** (add/select/drag/resize/send-to-back) — the follow-up `86ajq6j49` + interactions `86ajq6j4p` (design `86ajq6j29`). This batch exercises `Layer::Image` at the **scene/engine level** (construct a Frame with the layer → render → assert), like the element-model batch used compose tests.
- The **out-of-process sandbox worker** + IPC crash-containment + OS sandboxes (seccomp/AppContainer/App Sandbox) — ADR-0016 end-state, deferred.
- **JPEG/WebP/GIF/BMP** decode (→ placeholder + documented as later formats; their decoders aren't cached and JPEG determinism is risky); animation; **video/audio** (S8-8, spike-S2-gated); GStreamer→wgpu.
- **GPU-native image** compositing (later, alongside GPU glyphs — GPU keeps skipping `Layer::Image`). **Remote controller→host asset transfer** (a real image can't ride the 64KB control frame — host-local paths only this batch). Full **LRU/NFR-013**; **FR-138** import-path canonicalization (named seams).

### Constraints

- Determinism (NFR-014): a no-image scene renders **byte-identical** to today (parity + pinned tests are the guard); a PNG decodes byte-identically cross-OS (pure-Rust, RGBA8, no gamma). `Layer::Image` is GPU-skipped → the parity set is unchanged, SSIM stays ≥ 0.99.
- Bounded (no-leak): decode cache capped by entries **and** bytes with eviction; pre-alloc dimension/byte cap; decoded pixels never in the serde `Frame`. Bounded-memory test required.
- Panic-contained: decode is `Result`-based, no unwrap/expect; `selahcue-engine` stays `#![forbid(unsafe_code)]` (the `png` dep's internal unsafe is out of scope of that lint). A crafted image **contains to the placeholder**, never crashes (S8-6 acceptance).
- No wire/migration/RBAC change. fmt/clippy clean (workspace + operator); SBOM + RustSec audit green; 3-OS CI (parity is the determinism gate).

## Risks and rollback

- Risks: **ADR posture** — a bounded in-process decode deviates from ADR-0016's chosen out-of-process end-state (mitigated: ADR-0018 refines its *sequencing*, preserves fault isolation via DecoderFault→placeholder, defers security isolation explicitly). **Decompression-bomb / OOM** — a valid PNG can decode to gigabytes (mitigated: pre-alloc dimension + byte-budget cap + the png crate's own Limits; reject/placeholder over budget). **Panic on malformed input** — decoders can panic (mitigated: Result-based, no unwrap; adversarial tests; engine stays forbid(unsafe)). **Determinism** — a non-deterministic decode/scale breaks NFR-014 (mitigated: pure-Rust PNG → RGBA8 no gamma; integer nearest scale; golden test). **Supply-chain** — net-new deps trigger NFR-027 (mitigated: minimal pinned `png`, pure-Rust, RustSec green). **Serde/Eq breakage** — pixels in Frame or an f32 field would break byte-stability/Eq (mitigated: bounded ref not bytes; u8 opacity; fixture byte-stability test). Rollback: git; additive across the scene/raster layer; no wire/migration to revert.
