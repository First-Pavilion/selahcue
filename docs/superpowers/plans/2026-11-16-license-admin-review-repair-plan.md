## Review Focus

1. Equal/frozen clocks and two staff extensions interleaved with Free catch-up must leave a pending generation until a negotiated replacement; Task 2 pins this without timestamp inference.
2. A replacement committed remotely but lost before custody, followed by a no-secret replay while its token is still live, must allow only fresh explicit consented recovery on the same device; Tasks 3–4 pin both server and native transitions.
3. A sibling native process stores a newer token while an earlier refresh response/401 returns: the stale process must neither overwrite custody nor falsely retire pending identity; Task 4 pins the ownership/CAS check.
4. More than 500 earliest candidates share a held licence, and overlapping real worker deliveries arrive: an independent later licence must progress and the blocked work converge after release; Task 5 pins cursor/lock/deadline behavior.
5. CI has no binary, a stale-source binary, missing shared libraries or only skipped joint cases: the native/API gate must fail rather than report integration coverage; Task 1 supplies negative controls and Task 4 supplies actual new joint scenarios.
