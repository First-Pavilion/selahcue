## Intent and selected approach

Obtain one fresh macOS arm64 measurement of the recovered synthetic native adapter while the local compilation hold remains in force. Root has selected a manual, main-only `macos-26` job in the existing private repository, with a narrow tested cost-policy exception and separate official toolchain/public-crate provisioning. Root permits the finite synthetic inputs specified here in that repository. These are routine release-engineering dispositions under the user's CI-build request; this document does not ask the user to make them again.

Alternatives considered: (1) local compilation preserves the old machine but remains held by repeated active paging; (2) a preprovisioned offline hosted image avoids setup downloads but no verified seed exists; (3) a disposable standard arm64 runner with bounded setup followed by the immutable offline builder is the selected practical route. General macOS CI, recurring jobs, release packaging and a generic runner framework are outside this amendment.

This supersedes only the local-only/no-install limitation for this one proposed hosted proof. The local hold, frozen harness, source identities, fixture expectations, original notes model/budgets/custody and later bridge authority gates remain unchanged. It adds no provider calls, dynamic input/endpoint flags, paid inference, alternative inference engine, Apple signing, Tauri launch, DMG or installer acceptance.

Root dispositions following [the independent builder check](hosted-native-proof-builder-check-20261115.md) accept two engineering clarifications under the existing release scope: output byte bounds apply only to streams captured directly by the orchestrator; and a fixed post-upload cleanup interface removes only recorded job-owned paths. ### Serialization and constructors

`wire(value) = json.dumps(value, ensure_ascii=False, separators=(",", ":")).encode("utf-8")`, preserving insertion order, **without sorting keys**. `frame` inserts `options`, `draft_json` (decoded public UTF-8 string), `result_digest` (SHA256 of exact public bytes), then named extras in call order. Feed `b"\n".join(wire(frame) for frame in batch) + b"\n"`. Parse stdout one JSON object per line, require one result per frame, exit 0 and empty stderr; canonical observation digest uses that same `wire` on parsed objects in received key order, joined with terminal LF. Do not hash a reserialized public object in place of the embedded raw text.

Templates in order: `full_outline_scriptures`, `full_outline`, `summary`, `devotional`. Flags in order: `prayer_points`, `scripture_extraction`, `social_excerpts`, `chapter_markers`, `notable_quotations`, `short_summary`, `podcast_show_notes`, `short_description`. Default flags are `(True, True, False, True, True, True, False, False)`; default KJV. `options` insertion order is template, preferred_translation, include.

`teaching` inserts id/kind/text/source_blocks; defaults T000/movement/`Remain steady.`/[B0000]. `disposition` inserts block_id/teaching_ids/section_paths/excluded_reasons/repeats_teaching_ids; default B0000 and empty lists. `empty` inserts schema_version="1", outcome="complete", failure_code="none", teachings=[], source_dispositions=[transition-excluded disposition], outline=[], sections, section_links=[], quote_spans=[]. Empty sections insert title, main_scripture, supporting_scriptures, illustrations, quotes, prayer_points, calls_to_action, key_lessons, chapter_markers, introduction, summary (strings for title/main_scripture/summary, lists otherwise). `note` replaces teachings with one default teaching, outline with T000/no subpoints and disposition with T000 selected. Compile through recovered `compile_private(value, index_source(source), options)`, source default `Remain steady.`. `linked_sections` enumerates sorted section names, every list index and nonempty scalar, links each path to B0000, and sets the first disposition's section_paths. All these rules come from T1/N, not native outputs.
