## Approaches

The chosen approach adds one independently accepted console receipt inside the existing probe invocation and compares its document identity with the first settle poll. It preserves the current error-channel result alongside the receipt. This distinguishes successful collection from lost error forwarding and separates document replacement from state-reader failures. Raw exception logging would expose arbitrary content and still conflate stages; an unchanged rerun provides no new discrimination. No extra wait, route reduction, timeout increase, animation suppression or retry is part of this change.

## Contract

Own only implementation/marketing/scripts/responsive_sweep.py and implementation/marketing/tests/responsive_diagnostic_regression.py. Preserve the actual settle predicate, polling behavior, 10,000ms wait, all geometry/assertion/route/width coverage, existing single probe at timeout1000/polling100, failure exit2, and all prior test assertions. The configured probe timeout is not represented as a wall-clock cap.

Use a fixed version1 console protocol with exactly two kinds: document and probe. Prefix WEBKIT_SETTLE_PROBE followed by one space and strict JSON. Each body is at most768 ASCII bytes. The first actual settle poll emits one document record. Its test-owned nonce is32lowercase hexadecimal characters generated independently for each top-level document and kept separately from the state getter. A probe emits at most one probe record before its deliberate error-channel throw, even if getter read/call or scalar encoding fails. Browser state is untrusted: host validation rejects extra fields, malformed/nonstandard JSON, unexpected types/ranges, oversized bodies and duplicate records. Retain at most one first-poll record and one probe record; bounded rejection counters saturate at65535. No nonce, arbitrary text, URL, DOM content, cookie, credential, exception or page source is printed in final receipts.

Document record exact fields: version=1, kind=document, document=<nonce>. Probe record exact fields: version=1, kind=probe, document=<nonce or null>, outcome=<one of absent, non-callable, getter-threw, encoding-failed, nullish, snapshot>, state=<existing strictly validated settle-state object or null>, gateResult=<true, false, or read-error>. A snapshot requires valid existing state; other outcomes require null state. Preserve all existing state counter limits. A guarded single evaluation of the unchanged predicate supplies gateResult at probe time; it does not re-enter the gate or turn a timeout into success. Catch collection/encoding faults locally and send only the closed label.

The added host field is observation, with exact keys console, documentMatch, lifecycle and rejected. console is null or exactly {outcome,state,gateResult} using the admitted probe record; documentMatch is same/different/unknown; lifecycle has exact before and during dictionaries, each with close, crash and mainDocumentNavigation integer counts from0through65535; rejected is an integer0through65535. No raw nonce is exposed. Preserve legacy output for existing calls without an attached diagnostic where no observation is available.

Host evidence adds a bounded post-probe observation to the existing emitted WEBKIT_SETTLE_STATE result: accepted console outcome/state/gateResult, documentMatch=same/different/unknown, and whether close, crash or main-document navigation was observed before or during this one probe. Record only closed event names and finite counts, with before/during distinction; do not infer absence of an event proves a live document. Keep existing error-channel outcome/errorFamily/state/elapsedMs unchanged. The console observer must remain able to accept that single failure-time receipt even when the earlier12second generic journal cutoff has elapsed; it cannot reopen unlimited collection. Register/remove temporary listeners in guarded cleanup where suitable and preserve original failure on every observer/output error. Successful per-cell output remains quiet apart from existing named controls.
